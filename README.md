# 🚀 AI Resume Analyzer

An AI-powered Resume Analyzer that compares your resume with a job description using TF-IDF and provides a match score, missing skills, and improvement suggestions.


## 📌 Features

- 📄 Upload Resume (PDF)
- 📝 Paste Job Description
- 📊 Match Score using TF-IDF
- ❌ Missing Skills Detection
- 💡 Smart Suggestions
- ⚡ Fast and Simple UI (Streamlit)


## 🧠 How It Works

1. Extracts text from resume PDF
2. Cleans and processes text
3. Uses TF-IDF Vectorization
4. Calculates similarity using cosine similarity
5. Identifies missing skills from job description


## 🛠️ Tech Stack

- Python
- Streamlit
- Scikit-learn (TF-IDF)
- pdfplumber
